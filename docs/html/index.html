🚀 DevSecOps AWS

Apprenez à déployer une application complète sur AWS avec Terraform, Docker, ECS Fargate, et des pipelines CI/CD sécurisées.

Terraform Docker ECS Fargate GitHub Actions OIDC CodeQL Trivy
📘

Guide de Mise en Place — Étape par Étape

Guide complet et détaillé pour déployer le projet de A à Z. 15 étapes, ~2 heures, avec commandes et vérifications à chaque étape.

Bienvenue

Ce cours vous guide pas à pas dans la création d'un projet DevSecOps complet sur AWS. Vous apprendrez à :

  • Construire une infrastructure AWS robuste avec Terraform
  • Conteneuriser et déployer une application sur ECS Fargate
  • Mettre en place des pipelines CI/CD avec GitHub Actions
  • Intégrer la sécurité à chaque étape (DevSecOps)
  • Utiliser OIDC pour s'authentifier sans clés permanentes
ℹ️
Prérequis
Vous devez connaître les bases de Linux, Docker, et AWS (IAM, EC2, S3). Ce cours suppose que vous avez Terraform, Node.js, et Docker installés.

Quick Start

Terminal — Quick Start
# 1. Cloner le repository $ git clone https://github.com/ranimturkirt-sketch/aws-project.git $ cd projet-aws # 2. Bootstrap Terraform (remote state) $ cd terraform/bootstrap $ terraform init $ terraform apply # 3. Déployer l'infrastructure $ cd ../environments/dev $ terraform init $ terraform plan $ terraform apply # 4. Premier déploiement via git push $ git push origin main
⚠️
Coûts AWS
L'environnement DEV coûte environ 80 $/mois. Le NAT Gateway représente ~40% du coût. Pensez à détruire l'infrastructure après chaque session de LAB avec terraform destroy.
