## Public cible

Cette documentation s'adresse à des personnes qui connaissent :
- Les bases de Linux et la ligne de commande
- Docker et les conteneurs
- Les concepts fondamentaux d'AWS (IAM, EC2, S3)
- Git et GitHub

Chaque chapitre explique **pourquoi** chaque composant est nécessaire, pas seulement **comment** le configurer.
